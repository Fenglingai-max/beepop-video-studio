beepoptvc 本机助手 0.4（Windows / macOS + Kokoro 神经配音）

安装与启动
1. Windows 10/11：先安装 Node.js 22+ x64（https://nodejs.org/），完整解压安装包，再双击 start-beepoptvc.cmd。Windows ARM 设备使用 x64 版 Node.js。本版不需要 WSL、管理员权限或修改 PowerShell 执行策略。
2. macOS：安装 Node.js 22+ 或使用 Codex 自带的 Node.js，双击“启动beepoptvc.command”。
3. 首次启动联网安装锁定依赖：官方 Codex CLI、Remotion、Kokoro。随后下载并校验约 310 MB 的固定版本 Kokoro 模型以及 Remotion 浏览器。准备完成后模型留在 data/models 本机复用。只准备环境和连接账号不消耗 Codex 额度。
4. 保持启动窗口运行。官网点击“连接我的 Codex”，官方登录后核对本机账号并授权。Windows 和 Mac 使用同一官网。
5. 旧版升级：先完成正在制作的任务并关闭旧助手，再启动此版；在官网断开旧连接并重新连接一次，以更新配音声线列表。

制作与配音
- 商品理解、两张场景生图由当前已授权的 Codex 完成；视频由本机 Remotion 渲染。当前真实制作支持 15 秒横版。
- 本版使用本机 Kokoro-82M v1.0 神经配音，提供 10 个真实声线，默认 Bella（af_bella，与 4.0 咖啡罐案例声线相同）。JavaScript / ONNX 运行方式，无需额外安装 Python，也不需要配音 API Key。
- 固定自然语速 1.0，不做 atempo 强制加速。某句超过镜头时长时，请 Codex 缩短该句并重新配音，同步更新字幕；两次仍不适配时明确停止。
- 模型准备或神经配音失败不会回退为系统机器人配音。Kokoro 模型为 onnx-community 转换版；不是原 4.0 Python 运行时的逐字节同一输出，不承诺音频完全一致。
- 点击“生成视频”才使用已连接账号的 Codex 额度；配音在本机执行。原生生图失败会明确报错，不用商品动效冒充场景。

遇到问题
- Windows 双击 diagnose-beepoptvc.cmd；Mac 双击“运行环境检查.command”。检查系统、组件、官网网络、登录状态、生图能力与本地配音，不提交 Codex 生成任务。
- 结果在 data/diagnostics.json，试音在 data/voice-check.wav。原始 OpenAI 登录凭据不写入检查日志。
- OpenAI / ChatGPT 官方登录页的网络错误需单独检查网络和登录服务；安装 Windows 助手不会消除官方登录页错误。
- 主图短边至少 700 像素，其他图至少 200×200。生成场景是说明性画面，需核对商品结构、完整播放与试听后再使用。

数据与退出
- OpenAI 凭据由官方 Codex 保存在电脑。官网后台只中转本次商品资料、进度、成片，按连接隔离。
- data/relay.json 是设备连接凭证，请勿分享。data/ 和 node_modules 不在公开安装包中。
- 关闭助手会停止接收新任务，正在生成的任务可能中断。切换本机 Codex 账号会断开连接。

验证范围：源码合同与安全回归检查；Windows 实际执行情况以随发布的 Windows 自动构建检查结果为准。
