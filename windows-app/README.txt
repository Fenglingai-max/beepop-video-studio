beepoptvc Windows 助手 App 0.5.0 预览版

下载 beepoptvc-Assistant.exe 后双击。它是原生 Windows 窗口程序，内置已校验的 Node.js，不需要用户运行 CMD、BAT 或 PowerShell 启动文件。
适用于 Windows 10/11 x64，使用系统 .NET Framework（建议 4.8）。Windows ARM 机器需要系统支持 x64 应用。

首次会把应用复制到当前用户的 LocalAppData/beepoptvc，并创建“beepoptvc 助手”桌面快捷方式。制作组件、配音模型和渲染浏览器仍需首次联网准备，完成后复用。
打开 App 后自动准备助手。看到“助手已就绪”，再点击“打开官网”，连接自己的账号。仅开启 App 不提交生成任务，不消耗 Codex 推理额度。
若从旧脚本版切换，先完成旧任务并关闭旧助手。首次切换后，网页可能需要断开旧连接、再重新授权一次。

窗口中的“查看日志”和“复制诊断信息”用于反馈问题。错误会留在窗口中。关闭窗口会收进任务栏通知区域；右键图标可以停止或退出。需要登录 Windows 后自动启动时，勾选应用中的对应选项，默认不启用。
OpenAI 登录凭据继续由官方 Codex 保存；应用不读取 auth.json，不会把凭据打包或上传。助手控制令牌只在本机读取并发往 127.0.0.1。

试用版未购买商业代码签名证书，可能显示发布者未验证提示；不包含绕过系统、浏览器或企业安全策略的机制。正式分发可再配置代码签名。公司电脑的应用限制需要其管理员处理。
源码与构建脚本和 SHA256SUMS.txt 随同发布。原生应用的 Windows 构建、自检和窗口渲染预览通过后才发布下载。
