beepoptvc 连接更新 0.6.1（Windows 10/11 x64）

已安装助手的用户：双击 beepoptvc-Connection-Update.exe，点“更新并重启连接服务”。
更新只替换两个网络连接模块，保留配音模型、渲染组件、商品资料和已登录账号。
完成后可点“仅检查后台网络”，然后回官网重新点击“连接并授权”。
此更新不提交授权或生成任务，不消耗 Codex 额度。

新增：沿用 Windows 当前用户已配置的 HTTP/HTTPS 系统代理，或现有 HTTP_PROXY / HTTPS_PROXY。
本机 127.0.0.1、localhost 始终直连。不修改代理、防火墙、证书验证或系统设置。
仅存在浏览器代理扩展、PAC 或 SOCKS 配置时，无法保证自动继承；检测结果会说明当前方式。
后台拒绝请求时，显示实际 HTTP 状态和请求编号，避免只显示“暂不可用”。
有生成任务或仍在准备环境时，更新会停止，保护当前任务。

更新器未进行商业代码签名，适用于已有 App 版助手。
