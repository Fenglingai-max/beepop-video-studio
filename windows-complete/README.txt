beepoptvc Windows 完整版 0.6.1

适用：Windows 10/11 x64。
下载后双击 beepoptvc-Assistant.exe。首次在本机展开内置组件，完成后点“打开官网”。
配音模型、10 种声线、渲染浏览器、视频编码组件、Node.js 和官方 Codex CLI 均已内置。
准备组件不需要访问 npm、Hugging Face 或 Google 下载源。
OpenAI 登录、授权及生成仍需联网，使用你本人授权的账号额度。
不会调用系统机器人配音，不会自动提交视频生成。

旧版处于“准备未完成”时，直接启动此版即可替换失败的制作组件。
如旧助手还在执行任务或准备中，先等待结束；此版不会强制结束其他任务。
桌面会出现“beepoptvc 助手”快捷方式。重复双击新版会显示已打开的窗口。
关闭窗口保留在通知区域；右键图标可停止并退出。
“启动 / 修复”会在准备失败后重新从包内展开制作组件；不删除账号或产品资料。
“查看日志”汇总界面、后台标准输出和后台错误日志。

此构建尚未进行商业代码签名。无需管理员权限，不修改防火墙、TLS 验证或执行策略。

0.6.1：沿用已配置的 Windows 系统 HTTP/HTTPS 代理，并保留具体网络错误；回环地址直连。仅浏览器扩展或 PAC 不保证可继承。
