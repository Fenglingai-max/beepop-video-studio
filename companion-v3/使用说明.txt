beepoptvc 本机助手 0.3（macOS）

1. 需要 macOS、Node.js 22+、支持原生生图的 Codex CLI 或 ChatGPT 桌面版。
2. 解压后双击“启动beepoptvc.command”，保持助手运行。首次会安装锁定依赖。
3. 官网点击“连接我的 Codex”。在官方页面登录自己的 ChatGPT 账号，核对本机 Codex 为同一账号后授权。
4. 首次连接完成后，回到官网填写商品或一键复刻案例，选择声线，点击“生成视频”。无需每次打开本机制作页。
5. 生成顺序：商品理解与镜头编排 → Codex 原生生成两张全幅场景图 → macOS 英文配音与字幕 → Remotion 渲染 → 官网预览与下载。
6. 点击生成会使用当前已连接账号的 Codex 额度。图片使用 Codex 原生工具，不要求图像 API Key。原生生图失败时明确报错，不会用商品动效假装完成场景。
7. 官网与后台通道中转本次商品资料、任务进度和成片；OpenAI 凭据由官方 Codex 保存在电脑，不交给官网或通道。后台按连接隔离任务。
8. 配音使用本机 macOS 声线；当前支持 15 秒横版、1920×1080、30fps。场景为生成说明性画面，不是实际性能测试。
9. 任务文件位于 data/<任务ID>/。data/relay.json 仅保存后台通道的设备连接能力，不是 OpenAI 登录令牌，请勿分享。
10. 在官网断开连接，或切换本机 Codex 账号，会撤销当前设备连接。关闭助手会中断正在执行的任务。

主图短边至少 700 像素，其他图至少 200×200。上传素材应能准确表现商品结构。请完整播放、试听并核对商品与生成场景后使用。
仅已验证 macOS；竖版、20 秒和视频模型预设未接入此版真实制作。
