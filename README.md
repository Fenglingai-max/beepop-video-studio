# BeePOP 商品视频工作台

在线入口：https://fenglingai-max.github.io/beepop-video-studio/

三个独立制作版本：

| 版本 | 制作方式 | 时长 | 技能 |
| --- | --- | --- | --- |
| 商品视频TVC测试第一版 | 素材混剪、纯 Remotion，不调用视频模型 | 15–30秒 | tvc-2.0-upgrade |
| 商品视频TVC测试第二版 | 10秒真实视频 + 5–20秒原生 Remotion | 15–30秒 | tvc-v4 |
| 商品视频TVC测试第三版 | 全时段纯视频、至少五个独立真实摄影分镜 | 15–30秒 | tvc-v7 |

## 当前制作入口

用户选择版本，上传商品原图并指定素材用途，填写事实描述，选择时长、画幅和声线风格。第二、三版可选择 LibTV MiniMax H3、Seedance 2.5 或 Seedance 2.5 Flash；请求分辨率分别初始为 768p、720p，实际支持须在 LibTV 界面核实。

“准备制作任务”会整理参数和执行说明。“下载制作任务包”导出 ZIP，含 task.json、原始图片、每张图片 SHA256 及 Codex 执行说明。将任务包交给 Codex，安装随站提供的三版插件，使用用户已登录的 LibTV 官方页面制作。任务默认未授权付费生成次数；Codex 先核对参数、次数和额度再执行。当前站点不提交实际生成、不能读取 LibTV 登录状态，也没有视频生成 API。

声线为风格偏好，制作时按可用声线匹配试听。素材角色只是用户标注，事实、锁形、镜头和声音审查保持 pending，不能以任务导出代替审片。案例区使用用户实际测试视频30条，每版10条，案例区按版本切换；制作版本在输入区下拉项中选择。案例复刻载入对应商品资料、原始图片和制作设置，载入后可继续编辑；制作要求随任务包保留。视频按小文件传输，网页合并后播放、下载完整 MP4。

## 数据与兼容

草稿在当前浏览器 IndexedDB 保存，包括版本、模型、分辨率与图片角色。旧 TVC 2.0 草稿映射第一版，旧 see-dance-2.5 模型映射 Seedance 2.5；旧案例时长若超出所选版范围，按该版默认时长处理。图片只在用户主动下载时导出，不上传到第三方。

正式页面不再加载旧 codex-bridge.js，避免把第二、三版错误地提交到只支持15秒横版的旧服务。历史助手代码、下载清单和 CI 原样保留供后续兼容，不作为当前生成入口。

## 后续 API 接入约定

studio-contract.js 为独立版本合同。task.json 的 provider.mode 为 authenticated-browser、apiConnected 为 false、submitted 为 false。接入真实 API 时应新建经鉴权的服务端适配器；核对版本、模型、分辨率、预算和素材角色后才能提交，不得在静态站存储第三方密钥或抓取登录 Cookie。不能把准备状态显示为生成完成。

## 验证

本地预览：`python3 -m http.server 8080`，在浏览器打开 http://127.0.0.1:8080。
合同与ZIP测试：`node --test studio.test.cjs`。
本次未执行付费生成；完整生产验证需要 Codex 执行实际商品任务并审片。

网站按本次用户要求统一开放15–30秒的自由时长（滑杆与秒数输入，可输入小数，最高30秒），任务说明将其作为优先于技能缺省时长的用户要求。第二版固定采用10秒真实视频，其余5–20秒为Remotion；第三版按实际时长准备足量真实镜头。

首页最大主案例为第三版硅胶法棍烤盘。Seedance分辨率请求选项包括480p、720p、1080p；MiniMax保留768p、2K。

恢复原Codex连接与账号验证弹窗，使用原有授权中转服务；Codex连接不提交生成。LibTV登录与任务包制作流程保留。


本机直连 0.6：网页点击“生成视频”后，将本次资料通过受限来源的本机窗口交给 Codex；必要确认、进度和完整 MP4 直接回传，不要求手动安装三版插件或下载任务包。资源包内置规则及启动器，首次自动准备官方运行时、渲染和配音组件。使用者需已安装并启用官方 Codex 桌面环境的浏览器控制，使用自己的 Codex 和 LibTV 登录。

欧美市场输出固定英文旁白与英文字幕；历史中文声线迁移到英文默认声线。“我的项目”包含持久化制作记录，支持同账号重连恢复、预览和下载；技术检查通过但主观审片待完成的视频以 needs_review 状态提供预览。

0.7：最多接收10个后台项目，共享浏览器按任务排队；每次提交自动进入我的项目，任务快照持久化。第三版保留全部原技能并补充真实音轨指纹、样段时长/响度、旁白绑定、历史曲目与选曲记录检查；技术验证和真实听审分别标记，不伪造听审通过。完整混音组件通过官方PyPI固定版本及SHA256自动准备。

0.8：主任务只允许一次视频提交，交付完整版与剔除问题镜头的精剪版，后者可以短于目标时长；失败审片结论保留。用户在项目分镜编辑后，须再次明确确认补镜范围与一次生成预算，后台只生成选中镜头并使用原素材合成新版本，保留原版与修订记录。普通下载/项目预览使用内置受限工具与项目预览入口，执行器不申请命令越权；必要确认写入任务日志。

进度入口会保留当前查看项目编号，账号连接不恢复视频项目。完整版保留所有镜头与真实审片结论；精剪版仅用判定合格的片段，可短于15秒，不凑原时长。补镜在选中分镜并明确确认后才创建独立的一次提交任务，后台沿用原合格素材重新合成，关联到原项目的补镜记录。
