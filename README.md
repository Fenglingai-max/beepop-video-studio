# beepoptvc

商品视频制作交互原型，包含7款不同商品的完整案例视频、10款声线预设、横版/竖版和API模型预设。

声线和模型尚未接入实际生成服务。商品图片与草稿仅保存在访客浏览器内。

视频为网页压缩副本，点击播放时加载；原始测试成片单独保留。

视觉参考：https://beepop.ai/zh

在线体验：https://fenglingai-max.github.io/beepop-video-studio/

案例：咖啡罐、香水、希腊旗装饰签、土星灯、夏日露营推车、煎烤盘、万圣节幽灵灯；每款商品只展示一条。

每款案例支持一键复刻：点击后跳到现有制作区，载入原始产品文案、商品图片及生成场景。素材按点击加载；支持修改、移除图片及保存草稿。复刻仅带入资料，不自动提交生成任务。
